# KataWanted（指名手配リストViewer）

FiveM「KataCity」の指名手配リストを、ゲーム画面の左端に小さく表示するツールです（Windows 10/11、64 bit）。
人物名と残り時間をちらっと確認するためのもので、指名手配の書き込みと「済」（逮捕済みにする）もできます（EMS の許可済み）。

## ダウンロード

**最新版の exe（この リンクは版が上がっても変わりません）**:
https://github.com/gtabob1016/WantedViewer/releases/latest/download/WantedViewer.exe

落として、好きな場所に置いて起動するだけです。インストールは不要です。版ごとのページは右側の **Releases** にあります。

- ダウンロード時にブラウザが「一般的にダウンロードされていません」と止めることがあります（署名していない exe のため）。
  Edge: ダウンロード一覧の項目の「…」→「保存」→「詳細表示」→「保持する」。Chrome: 警告の横の「∧」→「保存」
- 初回起動で Windows の SmartScreen が「WindowsによってPCが保護されました」と出ることがあります。「詳細情報」→「実行」で起動できます
- 同じ Release の `WantedViewer.exe.sha256` と照合すれば、ファイルが改変されていないことを確かめられます
  （PowerShell: `Get-FileHash .\WantedViewer.exe -Algorithm SHA256`）

## 使い方

- 起動すると画面左上に一覧が出ます。ドラッグで移動、右端のドラッグで横幅、ホイールでスクロール
- ゲームなど、ほかのウィンドウを使っている間は、ツールはマウスに反応しません（クリックはゲームへ通ります）。ツールを触るときは Alt + Tab で KataWanted を選びます。設定の「動作」で変えられます
- 見出しの「KataWanted」を押すと、文字だけの小さな表示になります。もう一度押すと戻ります（ゲームの画面と重なるとき用）
- 設定の「動作」で「たたむ／戻すキー」を決めておくと、ゲームがアクティブなままそのキーで同じ切り替えができます（そのキーはゲームに届かなくなります）
- 右上の 📌 で固定（位置を動かせなくします）。もう一度押すと戻ります
- ⚙ で設定（文字の大きさ・色・透明度・並べ方・期限の表示など）。✕ で終了
- 名前にマウスを乗せると罪状・合計金額・状態が出ます（固定中は既定で出しません。設定の「動作」で変えられます）
- 行の「済」を押して OK すると、その人が逮捕済みになり、ツールを使っている全員の画面から外れます。「処理済み」タブの「戻」で戻せます
- 右下の鉛筆で指名手配を書き込めます。ゲームの指名手配文をそのまま貼って「送信」すると、EMS の入力フォームへ送ります（確認画面あり）。すでに一覧にいる人を貼ると「すでに登録されています」と出ます（全員が登録済みなら送信は押せません）
- 「処理済み」タブで、逮捕済み・期限切れを確認できます
- 人数が「同時に見せる行数」を超えると、一覧の端がオレンジに光ってスクロールできます（固定中も）。設定の「並べ方」で「自動で列を増やす」を ON にすると、あふれた分が右の列に出ます（横幅は自動で広がります）。OFF でも、右端をつまんで横に広げれば、広げた分だけ列が増えます
- 設定の「内容」で「表示モード」を「詳細」にすると、名前の下に罪状が出ます。「切れている名前を流す」を ON にすると、長い名前がときどき横に流れて全部読めます
- 設定画面は 5 つのタブ（文字と色・枠と線・並べ方・内容・動作）に分かれ、項目ごとに「変えるとどうなるか」の説明が付いています
- 右上の丸囲みの「i」を押すと、版と更新の有無が出ます。新しい版があれば「更新する」で更新できます

## 動作のしくみ

- EMS 用の指名手配スプレッドシート（Google フォームの回答を公開したもの）から作った「共有一覧」を 60 秒ごとに読み取ります。ログインは不要です
- 1 つの投稿に複数人いても 1 人 1 行で表示し、同じ人は期限が先のもの 1 件にまとめます。「逮捕したらチェック」が付いた人と、誰かが「済」にした人は「処理済み」タブに移ります
- 同じ手配かどうかは、名前と期限で判断します。捕まった人が別件（別の期限）でまた手配されたときは、指名手配中として出ます。無期限の手配は、捕まえた後に入ったものを別件として扱います
- 書き込むのは「済」（共有一覧の自分たちのシート）と、鉛筆からの指名手配（EMS の入力フォーム）の 2 つだけです。EMS のシートを直接書き換えることはありません
- 期限は PC の時計と比べて「あと〇〇分」で表示します。期限の分の間は「あと 0分」、その分が終わると「期限切れ」と出て、数秒後に「処理済み」タブへ移ります（書かれた期限より早く消えることはありません）
- 設定は `%LOCALAPPDATA%\WantedViewer\` に保存されます
- ゲーム（FiveM）には一切触れません。外部の小さなウィンドウを重ねているだけです
