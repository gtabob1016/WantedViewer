# 指名手配リストViewer

FiveM「KataCity」の公開指名手配リストを、ゲーム画面の左端に小さく表示する閲覧専用ツールです（Windows 10/11、64 bit）。
人物名と残り時間をちらっと確認するためのもので、登録・変更・逮捕処理はできません。

## ダウンロード

**最新版の exe（この リンクは版が上がっても変わりません）**:
https://github.com/gtabob1016/WantedViewer/releases/latest/download/WantedViewer.exe

落として、好きな場所に置いて起動するだけです。インストールは不要です。版ごとのページは右側の **Releases** にあります。

- 初回起動で Windows の SmartScreen が「WindowsによってPCが保護されました」と出ることがあります。「詳細情報」→「実行」で起動できます（署名していないためです）
- 同じ Release の `WantedViewer.exe.sha256` と照合すれば、ファイルが改変されていないことを確かめられます
  （PowerShell: `Get-FileHash .\WantedViewer.exe -Algorithm SHA256`）

## 使い方

- 起動すると画面左上に一覧が出ます。ドラッグで移動、右端のドラッグで横幅、ホイールでスクロール
- 右上の 📌 で固定（クリック透過。マウスはゲームへ通ります）。もう一度押すと戻ります
- ⚙ で設定（文字の大きさ・色・透明度・並び順・期限の表示など）。✕ で隠す（タスクトレイから戻せます）
- 名前にマウスを乗せると罪状・合計金額・状態が出ます
- 「逮捕済み」タブで、逮捕済み・期限切れを確認できます
- 右上の丸囲みの「i」を押すと、版と「更新を確認」が出ます。新しい版があればそこから更新できます

## 動作のしくみ

- 公開ページ（fox-rt.5858.nmddns.jp）の指名手配データを 60 秒ごとに読み取るだけです。ログインや書き込みはしません
- 期限は PC の時計と比べて「あと〇〇分」で表示し、過ぎたら一覧から外れます
- 設定は `%LOCALAPPDATA%\WantedViewer\` に保存されます
- ゲーム（FiveM）には一切触れません。外部の小さなウィンドウを重ねているだけです

## 更新

「i」→「更新を確認」。新しい版があれば「更新する」で置き換わります（GitHub から落として SHA-256 を照合してから置き換えます）。
